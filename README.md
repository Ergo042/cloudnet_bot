# nonebot-plugin-cloudnet-bot

_✨ 基于 NoneBot2 的 CloudNet 服务器管理插件 ✨_

</div>

## 📖 介绍

基于 NoneBot2 原生底层框架的 **CloudNet 网络管理插件**，配合 OneBot v11 协议，让你在 QQ 群/私聊中轻松管理 Minecraft 分布式服务器系统。
支持服务器快捷操作（启动/停止/重启/创建/销毁）、查看状态信息、以及绑定游戏内账号查询上线状态。

## 💿 安装

### 方式一：nb-cli 安装 (推荐)
```bash
nb plugin install nonebot-plugin-cloudnet-bot
```

### 方式二：pip 安装
```bash
pip install nonebot-plugin-cloudnet-bot
```
并在您的项目配置文件（如 `pyproject.toml` 或 `bot.py`）中加载该插件 `nonebot_plugin_cloudnet_bot`。

## ⚙️ 配置

为确保正常使用，需要在项目的 `.env` 或 `.env.*` 环境配置文件中添加相关的配置参数配置（例如 CloudNet API 服务地址、凭证以及 MySQL 数据库连接配置，详情请参考源码中的 `config.py` 文件）。

## 🎉 使用说明

插件支持以下控制指令（中英文符号及空格在此处配置为不敏感，且包含丰富的别名触发支持）：

### 📝 信息获取类指令
| 指令 | 说明 | 别名与快捷词 |
|:---|:---|:---|
| `cloudnet帮助` | 查看 CloudNet 管理系统的说明/帮助菜单 | `帮助`, `help`, `菜单`, `服务器帮助` |
| `获取服务器信息` | 列出当前所有服务器的状态信息（包含名称/状态/模版/CPU/内存使用率/在线人数/版本等） | `查询`, `查看服务器状态` |
| `获取在线人数` | 获取当前系统中的总玩家在线数 | `在线人数`, `查看在线人数` |
| `获取注册人数` | 获取整个 CloudNet 网络记录的总体注册人数 | `查询注册人数`, `注册人数` |
| `cloudnet查询上次登录`| 根据已绑定的QQ号（支持直接艾特或单独输入 QQ）查询此玩家上次登入游戏的时间 | `查询上次登录`, `上次登录`, `lastlogin` |

### 🔧 服务器生命周期管理指令
| 指令 | 说明 | 别名与快捷词 |
|:---|:---|:---|
| `创建服务器` | 交互式创建一个全新服务器，Bot 会列出可选的 Template 任务编号，用户通过交互提供编号即可完成部署 | `新建服务器`, `启动新服务器` |
| `删除服务器 [ID]` | 强制移除并销毁指定的服务器节点 | `移除服务器`, `销毁服务器` |
| `启动服务器 [ID]` | 启动指定的服务器节点 | `启动`, `开启服务器`, `运行服务器` |
| `重启服务器 [ID]` | 重启指定的服务器节点 | `重启`, `重新启动服务器` |
| `停止服务器 [ID]` | 正常停止或关闭指定运行中的服务器节点 | `关闭`, `关闭服务器`, `停止运行服务器` |

*注：`[ID]` 为您通过“获取服务器信息”中查看到的服务器单独识别名，如 `Lobby-2` 等。*

### 🎮 玩家与互动指令
| 指令 | 说明 | 别名与快捷词 |
|:---|:---|:---|
| `绑定账号 <游戏名>` | 绑定当前发送指令用户的 QQ 号码和对应的 Minecraft 游戏名（写入 MySQL 数据库） | `绑定游戏名`, `bind` |
| 无匹配兜底响应 | 假如呼叫命令错乱或不存在，Bot 会发出一则引导提示帮助指令列表 | - |

## 💡 注意事项

- 本插件依赖了 `nonebot-plugin-htmlkit`，可在渲染网页快照返回图文功能时调用。
- 初始化加载过程中包含了 MySQL 驱动建表（`init_db_tables`），请务必保证后端数据库可用。
- API 交互层级建立在对 CloudNet V3/V4 的 HTTP Base / Token Request 基础上运行，如连接异常，请检查防火墙过滤规则或服务心跳状态。
